HAVEN

Role Full-Stack Designer
Duration 6 Weeks

HAVEN is a premium hotel booking and management system designed around the principles of luxury minimalism. It features a beautifully crafted guest-facing booking interface, a comprehensive admin dashboard for reservations management, and real-time statistics tracking. The project demonstrates full-stack capabilities including form handling, data persistence, and interactive UI patterns.
