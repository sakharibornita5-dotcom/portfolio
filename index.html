HAVEN

Role Full-Stack Designer
Duration 6 Weeks
Stack HTML, CSS, JS

HAVEN is a premium hotel booking and management system designed around the principles of luxury minimalism. It features a beautifully crafted guest-facing booking interface, a comprehensive admin dashboard for reservations management, and real-time statistics tracking. The project demonstrates full-stack capabilities including form handling, data persistence, and interactive UI patterns.

Key Features
Guest booking system
Admin dashboard
Real-time statistics
Room catalog with details
Booking management (CRUD)
Search and filtering
Guest reviews section
Responsive design

Food Cuisines

Role Designer & Developer
Duration 4 Weeks
Stack React, Tailwind

Food Cuisines is an interactive platform celebrating culinary diversity around the world. The project showcases different cuisines, recipes, and food culture through an engaging, visually-rich interface. It demonstrates my ability to create compelling user experiences around content discovery and engagement.

Key Features
Cuisine directory
Recipe collection
Search functionality
Category filtering
Ingredient highlights
Responsive galleries
Interactive maps
Cultural storytelling
